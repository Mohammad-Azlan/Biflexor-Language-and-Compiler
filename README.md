# Biflexor-Language-and-Compiler
A compiler for a custom toy language Biflexor built on C++ using Flex and Bison

## Overview

**Biflexor** is a small C-style interpreted language featuring:
- Variables and arithmetic expressions  
- Control flow: `if`, `else`, `while`, `for`  
- Increment/decrement: `++`, `--`  
- Input/output: `read()`, `display()`  
- Custom IR (Intermediate Representation)  
- IR Executor (Virtual Machine)
- Dynamic typing like Python
